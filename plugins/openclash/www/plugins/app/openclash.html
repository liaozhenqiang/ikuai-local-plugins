自检与诊断
检查依赖命令、内核、geo、iptables/TPROXY 能力与运行状态, 出问题先看这里。
内核管理
内核只支持离线上传(不联网下载)。选本地已下载的 mihomo-linux-amd64-compatible-*.gz(约 23 MB), 上传后自动解压、校验 ELF 并试跑, 通过才落盘。 空间不足时可设 core_dir 到数据盘。
GEOSITE 数据
约 11 MB。装上后启用 GEOSITE 规则(广告拦截 + 细粒度域名分流)并重启内核; 没有也能用(自动降级为 GEOIP / IP 规则)。
维护
免回环列表: 把代理服务器 IP 设为直连, 防止路由器自己的流量绕进代理。 清理空间: 删除插件包归档/残留内核压缩包/坏 geo 数据。
免代理目标(直连, 不走 clash)
nps/npc 等对外服务若被透明代理劫走(表现为外网连不上), 把服务端 IP 加到这里即可直连。 手动添加的条目在刷新/重装规则后依然保留。
