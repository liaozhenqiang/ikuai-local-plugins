上游 DNS
—

AdGuard Home 是在 DNS 层做广告 / 追踪 / 钓鱼拦截，不依赖浏览器插件。
与 OpenClash 共存：「上游 DNS」选 自动 时，插件会检测是否装了 OpenClash——有则自动把上游指向它的 DNS(7874)， 实现「先去广告 → 再防污染/域名分流」的串联，两插件互不干扰、无需手动改配置；没装 OpenClash 时自动退回公共 DoH 独立运行。 想强制独立走公共 DoH 就点「公共 DoH」，想强制串联就点「OpenClash 串联」。
过滤规则、客户端管理、统计都在 Web 管理页里配置；插件只负责把它跑起来并管好端口、劫持与上游。
