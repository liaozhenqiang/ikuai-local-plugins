下载管理 (AriaNg)

当前是 HTTPS 访问管理页面：浏览器安全策略会拦截页面内的 AriaNg 连接 aria2 的 HTTP RPC（混合内容）。 （端口自动从路由器配置读取） 请改用路由器的 HTTP 管理地址打开本插件页面。
服务未运行，AriaNg 连不上 RPC —— 点上方「启动」后即可添加下载任务。
下方已按当前 RPC 端口/密钥自动配置好 AriaNg；手机横屏用「新窗口打开」体验更好

设置

RPC 端口 AriaNg 通过这个端口连 aria2；改端口会自动重启
RPC 密钥 相当于 AriaNg 的连接密码，建议保持复杂；泄露了改掉即可
下载目录 仅限 /etc/disk / /etc/mnt / /etc/disk_user 下；不存在会自动创建。换设备/换盘后点「自动探测」即可恢复默认路径
做种分享率 下载完成后继续上传的倍率，0 = 无限做种（NAS 常用）
DHT 磁力链解析需要 DHT；纯 HTTP/PT 可关 开机自启

运行日志 

（点「刷新日志」查看）

aria2 为静态 musl 构建（1.37.0），AriaNg 1.3.15 随插件分发，均无需额外依赖。
换设备/换磁盘：安装时自动探测本机最大的数据盘建 downloads 目录（UUID 是运行时探测的， 不写死）；旧路径失效时启动会自动重新探测，也可点设置里的「自动探测」一键恢复。
公网访问注意：RPC 端口（默认 6800）不要直接映射到公网——虽然密钥能挡住大部分扫描， 下载接口暴露仍有风险。推荐先连回内网（VPN）再访问本页面，或在路由器上只映射 Web 界面端口。
下载文件默认落在数据盘（容量最大的 /etc/disk/*/downloads）；插件持久盘 /etc/mnt 空间小，不建议当下载盘。
